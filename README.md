# 스튜디오 로그

음악 작업(작곡·녹음·믹싱·사운드 디자인)과 피아노 연습 일정을 함께 관리하는 반응형 웹앱입니다.

- `index.html` 파일 하나로 동작합니다. 브라우저에서 열면 바로 쓸 수 있습니다.
- 기록은 브라우저 `localStorage`에 자동 저장되며, 우측 상단 **백업**에서 JSON으로 내보내고 불러올 수 있습니다.
- 화면: 오늘 · 캘린더 · 작업실 · 피아노 · 통계 (폭 768px 이하에서는 하단 탭바)

- 반복 일정: 새 일정에서 매일·평일·매주(월~일 중 여러 요일 선택)를 고르고, 종료일을 정하거나(최대 1년) ‘종료일 없이 계속 반복’을 켭니다. 종료일이 없으면 1년 치를 만들어 두고 앱을 열 때마다 이어서 채웁니다. 날짜별 완료·삭제가 가능하고, 수정할 때 ‘이 일정만’ 또는 ‘이 날 이후 모든 반복 일정’(제목·분류·시간·메모·색)을 고를 수 있습니다. ‘이 날부터 반복 삭제’로 남은 묶음을 지우고 되돌릴 수 있습니다(되돌리기는 지운 회차와 반복 정의만 되살리며, 그 사이 다른 기기에서 바뀐 내용은 건드리지 않습니다). 지우거나 다른 날로 옮긴 회차의 날짜는 ‘다시 만들지 않을 날짜’로 기억되어 이어 만들 때 되살아나지 않고(백업 JSON·동기화에도 포함), 같은 반복의 다른 회차가 있는 날로는 옮길 수 없습니다. 옛 백업(반복 정의가 없는 파일)도 그대로 불러올 수 있고, 읽을 수 없는 항목만 건너뜁니다.
- 색상: 일정을 만들거나 고칠 때 일정별 색을 정할 수 있습니다. 상단 설정(슬라이더 아이콘)에서 요일별 색을 정하면 캘린더의 요일 칸·날짜 숫자와 오늘 화면의 이번 주 줄에 입혀집니다.
- 글자 크기: 상단 설정에서 일정 글자 크기를 8–24pt로 조절합니다(기본 11pt). 이 값은 기기마다 따로 저장됩니다.
- 메트로놈: 피아노 화면에서 20–300 BPM, 1–12박, 첫 박 강조를 설정합니다. 다른 화면이나 백그라운드로 이동하면 정지합니다.
- 선택한 B 콘솔형 아이콘을 HTML에 내장해 상단 로고와 브라우저 아이콘에 사용합니다. 홈 화면 아이콘 지원은 기기·브라우저에 따라 다릅니다.
- 기기 간 동기화: 상단 **동기화**에서 Google 계정으로 로그인하면 기록이 Firebase(Firestore)에 저장되어 다른 기기에 자동 반영됩니다. 두 기기에서 동시에 고쳐도 서로 다른 항목은 함께 합쳐지고(같은 항목을 서로 다르게 고치거나 한쪽이 지운 경우에는 알림을 띄웁니다), 올리지 못한 변경은 연결이 돌아오면 자동으로 다시 올립니다. 클라우드 문서를 읽을 수 없을 때는 이 기기의 기록을 지우지 않고 오류로 표시합니다. GitHub Pages 주소(https)에서만 동작하며, 내려받은 파일을 직접 열면 이 브라우저에만 저장됩니다.
- 일정 분류: 음악 작업 · 피아노 연습 · 알바 · 기타. 일정에 시작·종료 시간을 넣을 수 있습니다.
